# design/

Design studies and visual references for NeoTeam Social Run. `DESIGN.md` at the repo root is the rulebook; this folder holds the evidence and explorations behind it.

| What | Where | Name |
|------|-------|------|
| Studies, explorations, mockups (HTML, Figma exports, images) | `design/studies/` | `YYYY-MM-DD-<topic>.<ext>` |
| Screenshots used as before/after baselines | `design/baseline/YYYY-MM-DD/` | `<route-or-section>-<width>.png` (e.g. `admin-participants-390.png`) |
| Brand assets supplied by NeoTeam (logos, palettes) | `design/brand/` | as supplied |

Rules:

- Capture at **390 px first**, then 1024 and 1440.
- A study that becomes a decision is reflected in `DESIGN.md` (tokens or standing rules) in the same PR.
- No secrets, personal data or real participant information in screenshots: use test records.
